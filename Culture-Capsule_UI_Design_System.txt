2. DESIGN PRINCIPLES
--------------------------------------------------------------------------------

1. Extreme Rounding & Softness
   UI elements (cards, inputs, buttons) feature aggressive corner radii 
   (2.5rem to 4rem), creating a friendly, organic, and modern feel.

2. Glassmorphism & Depth
   Heavy usage of semi-transparent backgrounds (bg-white/5, bg-white/10), 
   background blurs, and layered gradients to establish hierarchy on dark backgrounds.

3. Vibrant Gradient Immersion
   The brand relies on deep, dark backgrounds illuminated by rich, moving gradients 
   of Blue (#0066FF), Purple (#7B3FF2), and Pink (#FF1B6D).

4. Typography as Texture
   Typography is not just for reading but for feeling. Massive italic serif headings
   contrast with clean sans-serif body text and handwritten accents.

5. Motion-First Interaction
   Static states are rare. Elements float, react to scroll (parallax), and 
   respond physically (scale, tilt) to user interaction.

6. MOTION & INTERACTION GUIDELINES
--------------------------------------------------------------------------------

Scroll Behavior:
• Lenis Smooth Scroll implemented globally.
• Parallax: Images and cards move at different speeds (scrub: 1).
• Reveals: Elements translate Y (50px -> 0) and fade in (opacity 0 -> 1).

Micro-Interactions:
• Buttons: Scale up (1.02 - 1.05) on hover, scale down (0.95 - 0.98) on tap.
• Links: Standard color transition (300ms).
• Cards: Hover lifts card (y: -10px) and creates shadow bloom.

Animation Specs (Framer Motion / GSAP):
• Entry Duration: 0.8s - 1.2s
• Easing: 'power3.out' (GSAP) or 'spring' (Framer)
• Stagger: 0.1s - 0.2s between list items

7. ACCESSIBILITY CONSIDERATIONS
--------------------------------------------------------------------------------
• Contrast:
  - High contrast maintained on Dark sections (White text on Deep Purple).
  - Light sections use dark gray/black text.
  - Low contrast text (text-white/40) strictly reserved for decorative/secondary info.
• Inputs: Focus states clearly defined with 'ring-purple-500'.
• Motion: 'suppressHydrationWarning' and client-side checks suggest adherence to
  rendering standards, though 'prefers-reduced-motion' not explicitly found in CSS.

8. RESPONSIVE BEHAVIOR
--------------------------------------------------------------------------------
Breakpoints (Tailwind Defaults):
• Mobile (default): Single column layouts.
• MD (768px): 2-column grids (Projects, Plans). Navbar switches to simplified.
• LG (1024px): 4-column grids (Footer). Larger Typography.

Specific Adaptations:
• Typography: 'clamp' used for Hero title to scale fluidly without breakpoints.
• Spacing: Padding reduces on mobile (px-6 is constant global padding).
• Navigation: Hides links -> Shows Hamburger menu on < MD.

10. USAGE RULES (DO / DON'T)
--------------------------------------------------------------------------------
DO:
• DO use 2.5rem+ border radius for all container elements.
• DO use italics for section headings to maintain brand voice.
• DO use 'text-white/40' for non-essential labels to reduce visual noise.

DON'T:
• DON'T use sharp corners (0px radius) on cards or buttons.
• DON'T use solid flat colors for primary backgrounds; use defined gradients.
• DON'T use default sans-serif fonts; always use 'Inter'.

11. SCALABILITY & HANDOFF NOTES
--------------------------------------------------------------------------------
• Extending: New sections should follow the "Dark Gradient" or "Clean White"
  alternating pattern to maintain rhythm.
• Icons: Add new icons from 'lucide-react' library only.
• Animation: Revert to GSAP for scroll-linked animations and Framer Motion for
